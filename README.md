# ✨ TaskFlow Pro

An advanced and modern To-Do Web Application built using HTML, CSS, and JavaScript.  
This project helps users manage daily tasks efficiently with a beautiful responsive UI and productivity-focused features.

---

https://delightful-dieffenbachia-d4dafa.netlify.app/

# 📌 Features

## ✅ Core Features
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Task Statistics
- Progress Bar
- Empty State UI
- Responsive Design
- Dark Mode
- Local Storage Support

# ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/ajawankarbhavanasri-sketch/taskflow-pro
```

2. Open project folder

```bash
cd taskflow-pro
```

3. Run the project

Open:
```bash
index.html
```

or use Live Server in VS Code.
